Latin variable WOFF2 subsets retrieved September 5, 2026 from Google Fonts.

- Inter: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- JetBrains Mono: https://fonts.gstatic.com/s/jetbrainsmono/v24/tDbv2o-flEEny0FZhsfKu5WU4zr3E_BX0PnT8RD8yKwBNntkaToggR7BYRbKPxDcwg.woff2

Their upstream SIL Open Font Licenses are included alongside the files.
Fonts are served from the guide's own origin. The site's content security
policy remains self-only; no runtime Google Fonts requests were introduced.
Characters outside these subsets use the declared system-font fallbacks.
